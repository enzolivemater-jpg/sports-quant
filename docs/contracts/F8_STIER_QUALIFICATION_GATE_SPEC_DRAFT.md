# F8 S-Tier Qualification Gate — Draft Ready Specification

Date: 2026-09-22

Status: DRAFT_READY__THRESHOLDS_PARTLY_DEFERRED

Pilot sport: FOOTBALL

## Objective

Make qualification fail closed.

A candidate selection is never qualified because several weak signals add up to a high aggregate score.

Critical gates are conjunctive:
a critical failure cannot be compensated by odds, expected return, narrative context or another strong metric.

## Canonical business states

- QUALIFIED
- WAIT
- REVIEW
- NO_BET
- BLOCKED

Precedence:
BLOCKED > REVIEW > WAIT > NO_BET > QUALIFIED

Decision snapshots are immutable.

## Mandatory gate families

### 1. Point-in-time integrity

Require:
- all decision-critical inputs PIT-eligible;
- no unresolved future leakage;
- reproducible cutoff snapshot.

Critical failure:
- BLOCKED.

### 2. Data quality

Require:
- critical fields available;
- source provenance;
- acceptable quality/freshness/verification/conflict states.

Critical unavailable/error data:
- BLOCKED when a valid decision is technically impossible.

Material information expected before cutoff:
- WAIT.

Ambiguous/conflicting critical context requiring human validation:
- REVIEW.

### 3. Model evidence

Require:
- approved Football model/version;
- market-family-specific evidence;
- valid lineage;
- no detected critical drift.

Champion/Challenger governance still applies.

### 4. Calibration evidence

Require:
- approved calibrator/version for the relevant market scope;
- calibration evidence status adequate for use;
- sufficient sample evidence under future OD-03/OD-04 rules.

Exact numeric thresholds remain unresolved.

### 5. Uncertainty

Require:
- uncertainty output exists;
- no critical uncertainty condition beyond future validated limits.

No LLM/human discretionary override.

### 6. P_safe

Require:
- P_safe generated by the approved deterministic pipeline;
- 0 <= P_safe <= P_calibrated <= 1.

Presentation classifications derive from P_safe.

No band by itself is enough for S-Tier qualification.

### 7. Edge

Require:
- valid point-in-time market no-vig probability;
- edge_safe computed.

Hard current invariant:
- edge_safe < 0 => not QUALIFIED.

OD-06 remains OPEN for any stricter positive threshold.

### 8. Context / Sports Intelligence

Require:
- critical context checked for the decision cutoff;
- unresolved material rumor/conflict cannot silently improve qualification;
- source hierarchy and cross-confirmation rules respected.

Context may:
- trigger WAIT;
- trigger REVIEW;
- widen uncertainty through validated mechanisms;
- trigger NO_BET.

Context cannot directly assign final P_safe.

### 9. Market Risk

Require:
- MR_base present for market.

Football Phase 1:
- 1X2 = MR2
- main total goals = MR2

MR is structural and cannot replace P_safe.

No dynamic composite Market Risk score is implemented while deferred.

### 10. Sport Predictability evidence

The explicit `predictability_evidence_gate` is mandatory.

Require:
- PIT-valid/versioned PredictabilityAssessment for sport × market_family when the production rule requires it;
- evidence status adequate under future validated thresholds.

Current numeric gate threshold:
NOT_DEFINED_DO_NOT_IMPLEMENT.

SP does not directly modify P_safe or edge.

### 11. Model agreement

If model-agreement policy is enabled:
- use validated definition.

OD-08 remains OPEN for exact method/threshold.

No arbitrary consensus count.

### 12. Backtest / validation evidence

Require model/calibrator scope to have:
- walk-forward OOS evidence;
- frozen final-test governance where required;
- documented Log Loss/Brier/calibration/ECE/sample size;
- reproducibility lineage.

Backtest ROI alone is insufficient.

### 13. Drift

Check:
- data drift;
- concept drift;
- calibration drift;
- model/market disagreement where applicable.

OD-09 remains OPEN for numeric thresholds.

Critical drift may block or demote qualification.

## Selection outcome semantics

### QUALIFIED
All mandatory gates pass for the current cutoff.

### WAIT
A material expected input has not yet arrived and a later pre-event reevaluation is possible.

Example:
official lineup expected soon.

### REVIEW
A material ambiguity/conflict requires human validation.

Human review may resolve evidence state but may not manually set P_safe.

### NO_BET
The opportunity does not satisfy qualification.

Examples:
- insufficient edge;
- insufficient probability evidence;
- uncertainty too high;
- calibration evidence insufficient;
- failed predictability gate once threshold exists.

### BLOCKED
A technically valid decision cannot be made.

Examples:
- PIT integrity failure;
- critical licensing restriction;
- corrupted critical data;
- impossible provenance.

## Cutoff resolution

At the final decision cutoff:
- unresolved WAIT -> NO_BET
- unresolved decision-critical REVIEW -> NO_BET
- technical/integrity/licensing impossibility -> BLOCKED

## Main parlay constraint

For the project's main parlay mode:
- combined P_safe must be >= 50%.

This is not permission to force a combination to reach a target price.

Every added leg must independently satisfy its required gates and improve the combined profile sufficiently under later optimizer rules.

## No compensating aggregate score

Do not implement:
`total_score = probability + context + edge + data_quality + ...`

where high values can offset a failed critical gate.

Diagnostic scores may exist later for ranking among already-qualified candidates, but not to override qualification requirements.

## Required output

Each evaluation snapshot should expose:
- decision_state
- event/market identity
- model version
- calibrator version
- P_raw
- P_calibrated
- P_safe
- probability band
- P_market_no_vig
- edge_calibrated
- edge_safe
- MR_base
- Sport Predictability evidence reference
- gate results
- reason codes
- decision_cutoff_at
- dataset/snapshot lineage

## Required tests

1. all gates pass -> eligible for QUALIFIED.
2. negative edge_safe -> cannot QUALIFY.
3. PIT failure -> BLOCKED.
4. material expected lineup missing before cutoff -> WAIT where policy marks it required.
5. unresolved WAIT at cutoff -> NO_BET.
6. critical source conflict -> REVIEW.
7. unresolved critical REVIEW at cutoff -> NO_BET.
8. missing calibration evidence -> cannot QUALIFY.
9. direct manual P_safe override impossible.
10. MR class does not change probability.
11. SP class does not directly change P_safe.
12. failed critical gate cannot be compensated by strong odds/edge.
13. drift critical state blocks/demotes according to approved rule.
14. decision snapshot immutable.
15. reason codes deterministic.
16. main parlay P_safe below 50% -> rejected in main mode.

## Explicit unresolved decisions

Do not invent:
- P_safe formula;
- uncertainty Champion;
- calibration-valid thresholds;
- minimum sample sizes;
- stricter positive edge threshold;
- model-agreement threshold;
- drift thresholds;
- Sport Predictability gate numeric threshold.

## Acceptance

F8 is green only when:
- every mandatory gate is explicit and testable;
- fail-closed behavior is proven;
- all unresolved thresholds remain unresolved in code/config;
- NO_BET/BLOCKED/WAIT/REVIEW semantics are deterministic;
- independent review finds no P0/P1 bypass path.
